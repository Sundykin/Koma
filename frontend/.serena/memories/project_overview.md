Koma frontend is a React 19 + TypeScript + Vite 6 app for an AI drama/video editor. Main frontend work lives under src/, with editor UI in src/components/editor/ and transition logic in src/services/transition/. Use npm scripts from frontend/package.json: `npm run dev`, `npm run build`, `npm test`, `npm run test:coverage`, and `npx tsc --noEmit` for type checks. On Darwin, standard shell utilities like git, ls, cd are available, but project work should prefer dedicated Claude tools for search/read/edit.
