# Koma Studio

Koma Studio 是一款面向 AI 漫剧、短剧和连续视频内容生产的桌面创作工具。它把剧本、角色、场景、分镜、图片生成、视频生成、语音、时间线剪辑和成片导出放在同一个本地工作台里，目标是让创作者从“一个故事想法”一路推进到“可发布的视频资产”。

> 本仓库仅用于发布 Koma Studio 的安装包、更新文件和版本说明。Koma Studio 不是开源项目，源代码不在本仓库提供。

## 下载

请在本仓库的 [Releases](../../releases) 页面下载最新版本。

常见安装包类型：

- macOS：`.dmg`
- Windows：安装版 `.exe` / 便携版 `.exe`
- Linux：`.AppImage`

如果你已经安装过 Koma Studio，客户端会通过发布仓库检测新版本，并在有更新时提示下载安装。

## 它能做什么

### 剧本创作与拆解

- 新建项目、管理剧集和创作进度。
- 在剧本编辑器中编写故事、对白和分镜基础文本。
- 支持 `@` 提及角色、场景、道具等项目资产，保持创作上下文统一。
- 使用 AI 辅助生成、润色和整理剧本内容。
- 从剧本中提取角色、场景、道具和可视化创作线索。

### 角色、场景与道具资产库

- 按项目统一管理角色、场景、道具和参考图。
- 为角色生成定妆照、服装图、动作参考和预览素材。
- 为场景生成环境图、氛围图和连续镜头参考。
- 为道具生成图片或视频参考，便于在后续分镜中复用。
- 支持资产版本留存，减少重复生成和重复整理。

### 分镜生产工作流

- 使用可视化分镜板组织镜头、画面描述、角色动作、对白和情绪节奏。
- 支持单张图、四宫格、九宫格、故事板等多种分镜图片模式。
- 支持电影级故事板提示词模板，用于制作更连贯的剧情、调度、光影和情绪递进。
- 支持分镜图片多版本管理，便于比较和切换不同生成结果。
- 支持批量生成分镜图片和分镜视频。

### AI 图片、视频与语音生成

- 支持多类 AI 能力接入，包括大语言模型、文生图、图生图、图生视频、参考生视频、首尾帧视频和语音合成。
- 可按项目配置不同模型渠道和参数。
- 支持参考图上传、远程 URL 缓存和失效重传，减少重复上传和等待时间。
- 支持把角色、场景、道具、上一分镜、故事板等作为生成参考，提升连续镜头的一致性。

> 注意：Koma Studio 是创作工具本体。部分 AI 能力需要用户自行配置可用的模型服务、API Key 或本地服务。

### 灵绘节点工作台

- 通过节点画布组织文本、图片、视频、音频、脚本、全景和 3D 导演工作台等创作节点。
- 支持节点之间传递上下文、参考图和生成结果。
- 支持单节点执行、选中执行和流程执行。
- 支持全景图节点，用于构建可环绕的场景背景参考。
- 支持 3D 导演工作台，用程序化人物、动物、道具和机位搭建镜头调度参考，帮助 AI 更稳定地理解空间关系和动作关系。

### 视频剪辑与导出

- 内置时间线编辑器，支持视频、图片、音频、字幕等多轨道编排。
- 支持关键帧动画、画面预览、撤销重做和常用快捷键。
- 支持将分镜生成结果继续组织成完整视频。
- 支持使用 FFmpeg 导出 MP4、WebM、GIF 等格式。
- 支持剪映草稿导出，方便进入后续剪辑流程。

### 本地项目与创作资料管理

- 项目数据优先保存在本地，便于管理大型素材和长期创作资产。
- 支持项目、剧集、分镜、素材版本和生成记录的统一组织。
- 适合个人创作者、小团队、AI 短剧工作流和批量内容制作场景。

## 适合谁

- 想用 AI 做漫剧、短剧、推文视频、小说改编视频的创作者。
- 需要管理角色、场景、道具和分镜资产的内容团队。
- 希望把“剧本 → 分镜 → 生成 → 剪辑 → 导出”串成一条工作流的用户。
- 需要稳定复用参考图、故事板和镜头调度的 AI 视频创作者。
