# refine-linghui-inline-node-panels

## Status

Draft

## Summary

将灵绘节点从"画布节点 + 浮动面板"双体结构重构为"折叠/展开卡片"一体化模型，消除节点与属性面板的割裂感。

## Motivation

当前灵绘节点存在以下体验问题：

1. **信息过载**：未激活的节点在画布上展示了完整的 LiteGraph 内联编辑器（文本域、输入框、图片上传区、结果预览），导致画布视觉噪声过大
2. **双重编辑入口**：节点本身有内联 widget 编辑器，选中后又出现浮动属性面板，两者功能重叠
3. **节点与面板割裂**：浮动面板虽然跟随节点定位，但视觉上仍是独立的"另一个窗口"，没有与节点形成整体感

用户期望：节点未激活时只展示基本信息和产物缩略图；点击激活后展开完整编辑面板；节点和面板在视觉上是一体的。

## What Changes

### 1. 节点双态渲染（折叠/展开）

- **折叠态（未激活）**：节点只显示标题栏、状态徽标、节点类型图标、连线端口。如果节点有运行结果，在标题下方展示产物缩略图（图片/视频封面/文本摘要）
- **展开态（激活）**：节点展开为完整卡片，包含所有属性编辑器、运行状态、进度条和结果预览。同一时间只有一个节点处于展开态

### 2. 移除独立浮动节点检查面板

- 移除当前的 `linghuiNodeInspectorPanel` 浮动定位逻辑
- 节点属性编辑器直接作为展开态节点卡片的一部分渲染在画布上
- 保留画布信息面板（工作区统计）和执行日志面板

### 3. 统一视觉语言

- 折叠/展开过渡使用平滑动画
- 展开态卡片与节点共享边框和背景色，形成视觉一体
- 折叠态节点紧凑小巧，减少画布空间占用

## Impact

- **修改的 spec**：`linghui-studio`（MODIFIED: Linghui Workspace Shell、Result Preview and Export）
- **代码影响**：
  - `linghuiNodes.ts`：重构 widget 注册，支持折叠/展开双态
  - `LinghuiCanvas.tsx`：管理节点激活状态，控制 widget 可见性
  - `LinghuiPropertiesPanel.tsx`：移除节点检查面板，保留工作区/日志面板
  - `LinghuiPage.tsx`：适配新的选中/激活交互
  - `LinghuiPage.css`：新增折叠/展开态样式
