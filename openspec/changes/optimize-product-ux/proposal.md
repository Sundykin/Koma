# Change: Koma Studio 产品体验优化 — 竞品对标 & 缺陷修复

## 竞品分析摘要

### 主要竞品

| 竞品 | 定位 | 核心优势 | Koma 差距 |
|------|------|----------|-----------|
| **Runway Gen-4 / Act-2** | 专业影视级 AI 视频 | 角色动作捕捉、镜头一致性、10s@24fps | Koma 缺少角色一致性控制、无动作捕捉 |
| **Kling 2.0** | 高质量写实视频 | 30fps 1080p、物理模拟、运动控制 | Koma 无物理模拟预览、分辨率选项有限 |
| **Pika 2.0** | 创意特效短视频 | 快速生成、丰富风格预设、社交分享 | Koma 风格预设少、无一键分享 |
| **Sora 2** | 全能型文生视频 | 原生音频同步、角色 Cameo、25s 长视频 | Koma 已集成 Sora2 但未充分利用音频同步 |
| **PopShort.AI** | AI 短剧专用 | 角色一致性、场景连贯、叙事控制 | 最直接竞品，Koma 在叙事连贯性上需加强 |
| **Atlabs AI** | 脚本到视频一站式 | 自动分镜、角色创建、配音、一键成片 | Koma 流程类似但自动化程度不够 |
| **VIVAShort** | AI 短剧生成 | 自动场景分解、角色设定、环境提示词 | Koma 功能覆盖但 UX 流畅度不足 |

### 竞品共性趋势（2025-2026）
1. **一键成片**：从脚本到成品视频的全自动流水线
2. **角色一致性**：跨镜头保持角色外观、服装、表情一致
3. **原生音频**：视频生成自带对白、音效、环境音
4. **实时预览**：生成前可预览效果，减少试错成本
5. **协作与分享**：团队协作、一键发布到社交平台

## Koma Studio 现状问题分析

### 一、产品缺陷（Bug 级别）

1. **Provider 连接测试全部是假的**
   - TTI/ITV/TTS 配置管理器的"测试连接"按钮全部是 `setTimeout(1000)` 模拟
   - 用户无法验证 API Key 是否有效，配置错误只能在实际生成时才发现

2. **多个 Provider 未实现**
   - Runway、Kling、ComfyUI TTI、Edge-TTS 均为 `throw new Error('not implemented')`
   - 用户选择这些 Provider 后会直接报错，无任何提示

3. **MCP 工具调用审批未实现**
   - `approveToolCall` / `rejectToolCall` 只有 `console.log`
   - AI 对话中的工具调用无法被用户审批或拒绝

4. **导出功能未完成**
   - `exportRenderer.ts` 中 FFmpeg 编码流程标注 `TODO: 实现实际的 FFmpeg 编码流程`
   - 用户无法真正导出视频文件

5. **OpenAI TTS 返回 Blob URL**
   - 标注 `TODO: 需要保存到文件并返回路径`，使用 Blob URL 作为临时方案
   - 生成的语音无法持久化保存

### 二、产品不足（体验级别）

1. **新手引导缺失**
   - 首次打开无任何引导，用户不知道从何开始
   - 三步流程（资产→分镜→视频）没有可视化说明

2. **错误反馈不友好**
   - AI 生成失败时只显示技术错误信息（如 API 错误码）
   - 缺少用户可理解的错误提示和重试建议

3. **批量操作体验差**
   - 批量生成图片/视频时无法暂停或取消
   - 进度显示不够直观，无法看到每个分镜的状态

4. **资产管理不够智能**
   - 角色/场景/道具没有自动去重
   - 跨剧集的资产复用需要手动操作

5. **分镜编辑器功能单薄**
   - 无法拖拽排序分镜
   - 无分镜预览模式（类似幻灯片播放）
   - 缺少分镜间的转场设置

6. **视频剪辑器基础**
   - 时间线操作不够流畅
   - 缺少基础转场效果
   - 无字幕样式编辑器

7. **项目管理粗糙**
   - 无项目模板
   - 无项目导入/导出
   - 无版本历史/撤销

## What Changes

### 第一优先级：修复核心缺陷
- 实现 Provider 真实连接测试
- 为未实现的 Provider 添加明确的"暂未支持"状态提示
- 修复导出流程，实现 FFmpeg 编码
- 修复 OpenAI TTS 文件持久化

### 第二优先级：提升核心体验
- 添加新手引导流程
- 优化错误反馈机制（用户友好的错误提示 + 重试）
- 批量操作增加暂停/取消/进度详情
- 分镜编辑器增强（拖拽排序、预览模式）

### 第三优先级：对标竞品功能
- 项目模板系统
- 一键成片工作流（脚本→自动生成全部资产→自动分镜→自动视频）
- 分镜转场效果
- 增强的字幕编辑器

## Impact
- Affected specs: `ui-components`, `export`, `asset-generation`, `model-providers`
- Affected code: `frontend/src/components/settings/`, `frontend/src/providers/`, `frontend/src/services/exportRenderer.ts`, `frontend/src/components/storyboard/`, `frontend/src/components/editor/`
