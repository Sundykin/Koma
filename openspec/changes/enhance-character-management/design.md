# Design: enhance-character-management

## Overview
将已有的角色资产生成功能通过弹窗形式集成到 `AssetManager`，提供完整的角色管理体验。

## Architecture

### Component Structure

```
AssetManager.tsx
├── CharacterGrid (现有，增强点击行为)
├── CharacterDetailModal (新建)
│   ├── CharacterForm (基础信息编辑)
│   ├── PromptPreview (提示词预览/编辑)
│   └── CharacterAssetEditor (复用已有)
└── CreateCharacterModal (新建)
```

### Data Flow

```
用户点击角色卡片
    ↓
打开 CharacterDetailModal
    ↓
显示角色信息 + 资产状态
    ↓
用户编辑/生成操作
    ↓
调用 characterAssetWorkflow 或 projectStore
    ↓
更新数据 + 刷新UI
```

## Key Decisions

### 1. 弹窗 vs 侧边栏
**选择弹窗**，因为：
- 角色详情内容较多（基础信息 + 三视图 + 视频 + 提取）
- 弹窗可提供更大的编辑空间
- 与现有 Shot 编辑弹窗风格一致

### 2. 提示词编辑时机
**生成前预览**，用户可：
- 查看系统自动生成的提示词
- 手动调整后再生成
- 保存自定义提示词到角色数据

### 3. 三视图生成策略
复用 `characterAssetWorkflow.generateThreeView`：
- 分三次请求分别生成
- 支持单个视图重新生成
- 支持手动上传替代

## Implementation Notes

### 提示词生成函数
复用 `characterAssetWorkflow.ts` 中的 `buildCostumePhotoPrompt`，但需要暴露出来让 UI 可以预览。

### 图片路径处理
使用 `electronService.fs.toLocalUrl` 转换本地路径为可显示的 URL。

### 状态管理
使用 React 状态管理弹窗内的编辑状态，保存时调用 `saveCharacters`。
