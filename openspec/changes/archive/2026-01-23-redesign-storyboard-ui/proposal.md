# Change: Redesign Storyboard UI

## Why
The current Storyboard UI layout is cluttered and the design is unreasonable, negatively impacting usability. A comprehensive redesign is needed to improve the visual hierarchy, user experience, and overall aesthetics, starting with the core Storyboard module.

## What Changes
- Redesign the Storyboard Editor layout for better space utilization and clarity.
- Improve the visual design of individual storyboard shot cards.
- Refine the interaction patterns for shot management (add, delete, reorder, merge).
- Update component styles to align with a more modern and clean design language (leveraging Ant Design).
- Optimize the display of script content, prompts, and media assets within the storyboard.

## Impact
- Affected specs: `ui-components`, `timeline-editing`, `storyboard-editor` (if exists or new)
- Affected code: `src/components/storyboard/`, `src/components/editor/`, and related styles.
