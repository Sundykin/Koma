# Proposal: refine-timeline-editor

## Status
Draft

## Why

当前 Koma 的视频剪辑编辑器存在以下问题：

1. **关键帧系统不完善**：虽然有关键帧数据结构，但缺少完整的 UI 交互（可视化编辑、拖拽调整、缓动曲线选择）
2. **拖拽交互体验差**：片段拖拽不流畅，缺少实时预览反馈
3. **属性编辑器缺失**：没有完整的属性面板来编辑片段的位置、缩放、旋转、不透明度等变换属性
4. **播放预览不稳定**：Canvas 渲染存在问题，关键帧动画未正确应用
5. **缺少自动打帧机制**：修改属性时需要手动创建关键帧，不够智能

参考项目 `electron-egg` 在以下方面实现更优：
- 简洁高效的关键帧插值算法（完整属性快照模式）
- 流畅的拖拽交互（实时预览、跨轨道移动）
- 完整的属性面板（支持关键帧标记）
- 稳定的 Canvas 渲染和变换应用

## What Changes

### 1. 关键帧系统重构
- 重构关键帧数据结构，采用完整属性快照模式
- 实现关键帧 UI 可视化（菱形标记、拖拽调整时间）
- 实现关键帧右键菜单（删除、复制、设置缓动）
- 实现自动打帧机制（修改属性时自动创建/更新关键帧）

### 2. 属性面板实现
- 创建 PropertiesPanel 组件
- 支持变换属性编辑（x, y, scale, rotation, opacity）
- 支持关键帧切换按钮（启用/禁用属性动画）
- 支持缓动曲线选择器

### 3. 拖拽交互优化
- 实现拖拽阈值检测（避免误触发）
- 实现实时位置预览（边拖边更新）
- 优化跨轨道拖拽反馈
- 添加拖拽时的轨道高亮

### 4. 播放引擎修复
- 修复 Canvas 渲染中的变换应用
- 集成关键帧插值到渲染流程
- 优化帧同步机制

### 5. 时间线 UI 优化
- 优化时间标尺刻度显示
- 优化轨道视觉层级
- 添加片段缩略图实时更新

## Affected Specs

- `timeline-editing`: 添加关键帧交互、属性编辑相关需求
- `media-playback`: 添加关键帧动画渲染相关需求

## Risks

1. **关键帧数据迁移**：需要处理现有关键帧数据结构的兼容性
2. **性能影响**：实时拖拽预览可能影响低端设备性能
3. **复杂度增加**：属性面板和关键帧 UI 增加代码复杂度

## Alternatives Considered

1. **保持现有结构，只修复 bug**：不够彻底，用户体验仍有问题
2. **完全替换为 electron-egg 代码**：不现实，两个项目架构差异大
3. **使用第三方时间线库**：丧失定制能力，与现有工作流集成困难

## Decision

采用渐进式重构方案：
- 保留 Koma 现有的组件拆分架构和 Zustand 状态管理
- 借鉴 electron-egg 的关键帧算法和交互模式
- 新增 PropertiesPanel 组件
- 优化现有组件而非重写
