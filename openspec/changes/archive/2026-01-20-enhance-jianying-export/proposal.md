# Proposal: enhance-jianying-export

## Summary

增强剪映草稿导出功能，修复目录结构问题，并添加高级特性支持（关键帧、滤镜、动画、音频淡入淡出、蒙版），同时提供编辑器 UI 支持和原生视频导出能力提示。

## Motivation

当前剪映草稿导出存在以下问题：

1. **目录结构嵌套问题**：导出时创建了多余的目录层级，导致剪映无法正确识别草稿
2. **功能缺失**：仅支持基础的轨道和片段导出，缺少：
   - 关键帧动画（位置、旋转、缩放、透明度等）
   - 滤镜效果
   - 视频/文字动画
   - 音频淡入淡出
   - 蒙版效果
3. **编辑器缺乏 UI**：用户无法在编辑器中设置这些高级属性
4. **导出能力不透明**：用户不知道哪些特性只能通过剪映草稿导出

## Scope

### In Scope

1. 修复剪映草稿导出的目录结构
2. 实现关键帧导出支持
3. 实现滤镜导出支持
4. 实现动画（视频入场/出场、文字动画）导出支持
5. 实现音频淡入淡出导出支持
6. 实现蒙版导出支持
7. 编辑器 UI 添加高级属性面板
8. 导出对话框显示功能兼容性提示

### Out of Scope

- 原生视频渲染引擎（超出当前范围）
- 剪映特效资源库集成
- 实时预览这些高级效果

## Dependencies

- 依赖 `add-jianying-export` 提案的基础实现
- 参考 `pyJianYingDraft` Python 实现

## Risks

- 剪映版本更新可能导致格式不兼容
- 部分特效 ID 可能随剪映版本变化
