# 灵绘画布回归清单

## 1. 节点创建与基础交互

- 双击画布空白可创建节点，创建后自动打开对应编辑器。
- 图片、视频、音频文件拖入画布后会生成匹配节点，且节点名称、预览与模式正确。
- 鼠标模式下左键框选节点，手模式下左键拖动画布，滚轮/双指缩放行为符合当前模式定义。
- 复制、粘贴、副本、删除、撤销、重做在单节点、多节点和工作流块场景下都可用。

## 2. 工作流块与模板复用

- 框选节点后出现“创建工作流块”浮层，创建后保留选区范围和节点相对位置。
- 工作流块支持双击重命名、右键取消工作流块、整块运行、整块导出。
- 工作流块可保存为工作流模板，并能从工作流抽屉重新发送到当前画布。
- 工作流块相关文案统一为“工作流块”，不再混用“分组”作为用户可见术语。

## 3. 新节点体系执行闭环

- 文本、图片、视频、音频、脚本节点都支持折叠态、轻编辑态、沉浸式态三层视图切换，且折叠与沉浸偏好能正确反馈到节点外观。
- 文本节点支持手动输入与 LLM 生成，两种模式都能被下游引用。
- 图片节点支持上传/生成双模式，图生图时优先使用当前节点的提示词与参考，而不是错误继承上游首节点内容。
- 视频节点支持多模态输入聚合、首尾帧与参考输入摘要展示。
- 音频节点支持上传、本地播放、TTS 生成、结果写回当前素材与保存为资产。
- 脚本节点支持卡片/表格视图、派生图片与视频批量生成入口。

## 4. 提示词引用与结果复用

- `@` 引用列表能展示上游产物缩略图和名称，不被外层容器裁切。
- 提示词编译后的 `@Image N` 顺序与编辑器中“上游输入”展示顺序保持一致。
- 图片引用在编辑器中以 `image + 名称` 形式展示，悬浮时可查看更清晰的预览信息。
- 历史记录、资产抽屉和节点结果区都可以把结果重新发送回画布继续编排。

## 5. 稳定性与保存

- 自动保存仅订阅文档状态，不应导致画布无意义重渲染或视口跳动。
- 切换工作区、导入导出、刷新模板库后，工作流块与节点统计仍保持一致。
- 运行失败节点支持失败定位、失败重试和受影响节点重跑。
