# Proposal: timeline-features-completion

## Status
Draft

## Why

对比参考项目 `electron-egg` 和 `capcutDemo`，Koma 时间线编辑器缺失大量核心功能：

### 功能缺失对比

| 功能 | electron-egg | capcutDemo | Koma 现状 |
|------|-------------|------------|-----------|
| 片段右键菜单 | ✓ 删除/复制/添加关键帧 | ✓ | ✗ 完全没有 |
| 片段复制粘贴 | ✓ Ctrl+D 复制 | ✓ | ✗ 标注"开发中" |
| 添加关键帧快捷键 | ✓ K 键 | ✓ | ✗ 无 |
| 关键帧复制粘贴 | ✓ | ✓ | ✗ 标注"开发中" |
| 撤销/重做 | ✗ | ✓ | ⚠️ 重做逻辑不完整 |
| 多选片段 | ✗ | ✓ | ✗ 无 |
| 跨轨道拖拽高亮 | ✓ 青色边框 | ✓ | ⚠️ CSS有但未实现 |
| 关键帧曲线编辑器 | ✗ | ✓ | ✗ 无 |
| 工具栏播放控制 | ✓ | ✓ | ✗ 无 |

### 用户体验问题

1. **片段操作不便** - 无右键菜单，只能用快捷键
2. **关键帧添加繁琐** - 必须去属性面板点击
3. **无法复制片段** - 重复素材需要重新拖放
4. **撤销不可靠** - 重做功能实际不工作

## What Changes

### 阶段 1：片段右键菜单（高优先级）

1. **创建 ClipContextMenu 组件**
   - 删除片段
   - 复制片段
   - 在当前位置添加关键帧
   - 分割片段
   - 属性（跳转到属性面板）

2. **集成到 ClipItem**
   - onContextMenu 事件处理
   - 菜单位置计算

### 阶段 2：片段复制粘贴

1. **实现 copyItem / pasteItem**
   - 剪贴板存储选中片段数据
   - 粘贴时在播放头位置创建副本
   - 支持 Ctrl+C / Ctrl+V 快捷键
   - 支持 Ctrl+D 快速复制（副本放在原片段右侧）

2. **更新 trackStore**
   - 添加 clipboardItem 状态
   - 添加 copySelectedItem / pasteItem 方法

### 阶段 3：关键帧快捷操作

1. **K 键添加关键帧**
   - 在当前播放头位置
   - 添加到选中片段
   - 属性值使用当前插值或默认值

2. **关键帧复制粘贴**
   - 复制选中关键帧
   - 粘贴到当前时间位置

### 阶段 4：撤销/重做完善

1. **修复重做逻辑**
   - 保存完整状态快照而非操作记录
   - 重做时恢复状态

2. **补全操作历史记录**
   - 所有片段操作纳入历史
   - 所有关键帧操作纳入历史

### 阶段 5：跨轨道拖拽高亮

1. **实现拖拽目标轨道检测**
   - 使用 elementsFromPoint 检测
   - 高亮目标轨道

2. **实现跨轨道移动**
   - 拖拽片段到其他轨道
   - 验证轨道类型兼容性

### 阶段 6：工具栏增强

1. **添加播放控制按��**
   - 播放/暂停
   - 跳到开头/结尾

2. **添加撤销/重做按钮**

## Affected Specs

- `timeline-editing`: 添加右键菜单、复制粘贴需求
- `keyframe-animation`: 添加快捷键需求

## Risks

1. **状态管理复杂度** - 剪贴板和历史记录增加状态
2. **回归风险** - 修改核心拖拽逻辑
3. **性能影响** - 状态快照可能占用内存

## Alternatives Considered

1. **只做最小功能集** - 用户体验仍差
2. **使用第三方编辑器库** - 与现有代码不兼容

## Decision

分 6 个阶段实施，优先完成片段右键菜单和复制粘贴，这是用户最常用的功能。

## Success Metrics

- 片段右键菜单可用
- Ctrl+C/V/D 复制粘贴可用
- K 键添加关键帧可用
- 撤销/重做可靠工作
