## 二、存储方案分析 - STORAGE_COMPARISON.md

### 当前方案: JSON 文件
- 优点: 简单、易调试、用户可编辑
- 缺点: 大文件性能差、无事务、无索引

### 推荐方案: 混合（JSON + SQLite）

| 数据类型 | 存储方式 | 理由 |
|----------|----------|------|
| 项目元数据 | JSON | 用户友好、易读 |
| 全局设置 | localStorage | 简单 |
| 任务队列 | **SQLite** | 需要事务保护 |
| 时间线 | **SQLite** | 数据量大 |
| 角色/场景/分镜 | **SQLite** | 需要关联查询 |
| 资产文件 | 文件系统 | 二进制 |

**技术选型**: better-sqlite3（Electron 原生绑定，性能最好）

## 四、关键决策

### 1. 存储方案
**决策**: 采用混合方案（JSON + SQLite）
- 项目元数据保持 JSON（用户友好）
- 核心数据迁移到 SQLite（性能+安全）
- 使用 better-sqlite3

### 2. 架构重构
**决策**: 先修循环依赖，再做功能迁移
- 循环依赖影响构建稳定性，必须先修
- Service→Workflow 迁移可以渐进式进行

### 3. 类型安全
**决策**: 分阶段开启 strict
- 先修复 P0/P1 问题
- 再逐步开启 noImplicitAny
- 优先处理 IPC 边界
