# Koma 用户体验分析报告

> 分析日期：2026-02-03
> 分析范围：frontend/src/components/ 全部 UI 组件

---

## 概述

本报告从用户角度分析 Koma 项目的完整使用流程，包括新用户上手、核心操作流程、错误处理和功能缺失。问题按严重程度排序。

---

## 严重问题 (Critical)

### 1. 无新用户引导流程

**影响**：用户首次打开应用时直接面对空的项目列表，没有任何引导说明

**现状**：
- `ProjectList.tsx` 空状态只显示"创建第一个项目"按钮
- 无欢迎弹窗、教程或操作提示
- 用户不知道 Koma 能做什么、怎么做

**建议**：
- 首次启动显示欢迎引导流程
- 添加上下文帮助提示
- 提供文档/视频教程链接

### 2. 禁用的 UI 元素缺少解释

**影响**：用户看到灰色按钮但不知道为什么不能点击

**受影响组件**：
- `ProjectOverview.tsx`: AI 拆分按钮在剧本为空时禁用，但无提示说明
- `ProjectMediaSelector.tsx`: 多个选择器在无配置时禁用，无说明
- `InlineProjectToolbar.tsx`: 分析/生成按钮禁用但无原因

**建议**：
- 所有禁用按钮添加 Tooltip 说明禁用原因
- 提示如何启用该功能

### 3. 破坏性操作缺少确认

**影响**：用户可能意外丢失数据

**现状**：
- 项目删除有确认弹窗 ✓
- 剧本导入/替换会静默覆盖现有内容，无确认
- 部分剧集操作缺少确认

**建议**：
- 所有破坏性操作添加确认对话框
- 预览将被影响的内容

---

## 高优先级问题 (High)

### 4. 错误信息不友好

**影响**：用户无法理解错误原因或如何解决

**示例**：
- `ExportDialog.tsx`: 直接显示 `(err as Error).message` 技术错误
- `SimpleExportDialog.tsx`: 错误无上下文说明
- 全部资产面板: `err.message || t('asset.saveFailed')` 不解释根本原因

**建议**：
- 将技术错误映射为用户友好的消息
- 提供纠正建议
- 技术详情记录日志，UI 显示简化信息

### 5. 表单必填字段无标识

**影响**：用户不清楚哪些字段必须填写

**问题**：
- `CreateProjectModal.tsx`: "项目名称"必填但无红色星号标识
- 表单验证错误仅在提交后显示，无实时反馈

**建议**：
- 必填字段添加 * 标识
- 实时验证反馈
- 字段级帮助文字

### 6. 步骤进度不清晰

**影响**：用户不知道当前进度和完成状态

**现状**：
- 使用 `StepNavigator` 显示步骤 (assets → storyboard → video)
- 长时间操作无进度反馈
- 中途退出后不清楚之前进度

**建议**：
- 添加持久面包屑显示完成百分比
- 操作中显示进度条
- 自动保存中间进度

### 7. 分镜空状态无引导

**影响**：用户到达分镜步骤但不知道如何开始

**现状**：
- `Storyboard.tsx` 空状态显示"暂无分镜数据"但无操作按钮
- 无"从剧本生成"的明显入口
- 无导入选项

**建议**：
- 增强空状态设计，添加视觉引导和快捷操作
- 解释什么是镜头及其属性

### 8. 加载状态缺少时间预估

**影响**：用户不知道操作需要多长时间

**问题**：
- 导出进度显示百分比但无预计剩余时间
- 资产生成只显示加载动画
- 各组件进度提示不一致

**建议**：
- 显示预计剩余时间
- 显示当前阶段名称（如"渲染中: 第 100/300 帧"）
- 所有长时间操作显示取消按钮

---

## 中等优先级问题 (Medium)

### 9. 自动保存无反馈

**影响**：用户不确定更改是否已保存

**现状**：
- `ScriptWorkbench.tsx`: 2秒防抖自动保存
- `SaveStatusIndicator.tsx` 存在但未在所有编辑场景集成

**建议**：
- 头部显示持久保存状态（✓ 已保存 / ⋯ 保存中 / • 未保存）
- 首次保存后显示提示
- 离开时提示未保存更改

### 10. 配置选择复杂

**影响**：用户被模型/服务商选项淹没

**现状**：
- `ProjectOverview.tsx`: 顶部 4 个下拉框 (LLM, TTI, ITV, TTS)
- 无默认推荐，无各选项说明

**建议**：
- 推荐配置显示"默认"标签
- 内联帮助说明各模型用途
- "一键配置"自动选择合理默认值

### 11. 剧集管理体验碎片化

**影响**：剧集选择和编辑流程混乱

**问题**：
- 无法快速预览剧集内容
- 当前选中剧集不够明显
- 多处显示"未选择剧集"警告

**建议**：
- 清晰的选中状态视觉指示
- 拖拽手柄带视觉反馈
- 悬停时快速预览

### 12. 视频编辑器缺少基础功能

**影响**：用户无法执行基本编辑任务

**缺失**：
- 时间线悬停位置不明显
- 无对齐吸附视觉反馈
- 键盘快捷键帮助隐藏较深
- 无撤销/重做可视化

**建议**：
- 浮动时间位置指示器
- 吸附引导线高亮
- Cmd/Ctrl+? 快捷键叠加层

### 13. 导出兼容性警告不清晰

**影响**：用户可能导出不支持的格式导致效果丢失

**现状**：
- `SimpleExportDialog.tsx` 显示剪映专属功能警告
- 警告仅视频导出显示，草稿导出不显示

**建议**：
- 提前说明格式限制
- 各格式支持功能对比表
- 根据项目使用的功能推荐格式

### 14. 后台任务无反馈

**影响**：用户不确定系统是否在工作

**示例**：
- 剧本分析无进度显示
- 批量图片生成任务栏容易被忽略
- 视频渲染可能看起来像卡住

**建议**：
- 关键操作时固定任务通知区域
- 任务完成/失败时 Toast 通知
- 完成时声音/视觉提醒

### 15. 资产面板空状态无帮助

**影响**：用户不知道如何开始创建资产

**缺失**：
- 无"什么是好资产"的分步指南
- 无示例资产参考

**建议**：
- 链接示例资产
- 快速开始模板
- 字段级帮助提示

---

## 低优先级问题 (Low)

### 16. 错误处理模式不一致

**影响**：部分错误显示给用户，部分静默记录日志

**现状**：约 30+ 处 `console.error()` 无用户反馈

**建议**：确保所有错误通知用户

### 17. 键盘快捷键文档缺失

**影响**：高级用户无法发现效率功能

**建议**：
- 右上角可访问的帮助菜单
- Cmd+? 显示快捷键叠加层

### 18. 表单样式不一致

**影响**：视觉不统一

**示例**：
- 部分使用 antd Input，部分使用原生 input
- 占位文字质量参差不齐
- 聚焦状态不明显

**建议**：创建统一的表单输入组件封装

### 19. 高级功能缺少入门引导

**影响**：用户不知道 MCP、插件等高级功能

**建议**：每个功能添加简介和文档链接

### 20. 分镜属性过于复杂

**影响**：普通用户被太多字段淹没

**建议**：
- 折叠高级选项
- "快速编辑"模式只显示核心字段
- 基于剧本内容的智能建议

---

## 工作流痛点

### 剧本编辑
- 无实时拼写检查
- 剧本分析失败无重试机制
- 手动创建剧集繁琐

### 分镜生成
- 无法预览 AI 生成的镜头再确认
- 无校对模式查看效果
- 批量操作无确认即执行

### 视频导出
- 导出设置（分辨率、帧率、编码）无说明
- 无文件大小预估
- 导出无法暂停只能取消

---

## 建议优先级

### 快速修复 (1-2小时/项)
1. 所有禁用按钮添加 Tooltip
2. 表单必填字段添加视觉标识
3. 关键操作时固定任务通知栏
4. 所有编辑场景添加保存状态指示
5. 改善错误信息

### 中等工作量 (半天/项)
1. 创建欢迎/引导流程
2. 添加键盘快捷键帮助叠加层
3. 增强空状态组件引导
4. 长时间操作添加时间预估
5. 表单提交前验证反馈

### 较大工作量 (1天+)
1. 重新设计分镜空状态
2. 创建完整用户指南
3. 撤销/重做可视化
4. 资产创建智能字段建议
5. 导出前增强预览

## 组件问题汇总

| 组件 | 问题数 | 严重程度 |
|------|--------|----------|
| `App.tsx` | 无引导流程 | Critical |
| `ProjectList.tsx` | 空状态和删除确认已完善 | ✓ Good |
| `ProjectOverview.tsx` | 禁用按钮无提示、配置选择复杂 | High |
| `EditorView.tsx` | 步骤进度不可见 | High |
| `Storyboard.tsx` | 空状态无帮助、缺少 CTA | High |
| `ExportDialog.tsx` | 通用错误信息、无时间预估 | Medium |
| `SimpleExportDialog.tsx` | 兼容性警告混乱 | Medium |
| `EpisodeManager.tsx` | 拖拽无反馈、多处警告 | Medium |
| `AssetManager*.tsx` | 资产创建流程不清晰 | Medium |
| `ScriptWorkbench.tsx` | 静默自动保存、无验证反馈 | Medium |

---

## 总结

Koma 具备良好的错误处理基础设施，但在用户反馈、引导和流程清晰度方面存在显著差距，影响用户效率和信心。建议优先解决新用户引导、禁用状态说明和错误信息优化这三个关键问题。
